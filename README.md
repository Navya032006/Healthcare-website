# 🏥 Healthcare Website

A complete **Health Care Management System** developed using **HTML, CSS, JavaScript, PHP, and MySQL**.
This web application allows users to register, log in, and book doctor appointments online.
It is designed to simulate a real-world healthcare service platform with both frontend and backend functionality.

---

## 📌 Problem Statement
Healthcare services require an efficient and user-friendly system to manage patient interactions,
appointments, and basic medical service information.
This project provides a web-based solution to help patients easily access healthcare services online.

---

## 🚀 Features
- Patient registration and login system
- Secure authentication using PHP sessions
- Online doctor appointment booking
- Doctor selection during appointment scheduling
- Ambulance emergency contact information
- Contact form for user support
- Responsive user interface

---

## 🧱 Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- PHP (Core PHP)

### Database
- MySQL

---

## ▶️ How to Run Locally

1. Clone the repository  
   `git clone https://github.com/Navya032006/Healthcare-website.git`

2. Create a database  
   - Open phpMyAdmin or any MySQL tool  
   - Create a database named: `health_care`

3. Import the database  
   - Import the SQL file provided in the project  
     (`health care.sql`)

4. Configure database connection  
   - Open `db_config.php`  
   - Update database username and password

5. Start the server  
   - Use XAMPP / WAMP / Laragon  
   - Place the project folder inside `htdocs`

6. Open in browser  
   `http://localhost/Healthcare-website/home.html`
